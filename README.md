## 日本云服务器推荐里很少提的一件事：2.5Gbps 配 1TB 流量意味着什么

端口带宽和月流量是两个独立的数字，很多人会把它们混成一个。

2.5Gbps 换算下来是每秒 312MB 左右。1TB 是 1024GB。按理论峰值一直跑，1TB 流量在 55 分钟前后就会用完。也就是说，JPHyper-Lite 那个 2.5Gbps 的端口，代表的是一瞬间能冲多快，不代表一个月能用多少。真正限制你的是那 1TB。

这个区别在实际使用里的表现是：看视频、开网页、跑代理、同步文件，1TB 一个月基本用不完；做下载站、CDN 回源、给朋友分发大文件，几个小时就能把额度跑光。

所以看到“2.5Gbps 大带宽”这种描述，先去找月流量那一栏的数字。端口再大，流量给 1TB，它就是一小时的峰值能力。
